# Alter

Desktop studio for Mac and Windows.

## Download

**Share this page:** https://printsfluent.github.io/alter-desktop/

Direct latest release: https://github.com/Printsfluent/alter-desktop/releases/latest

- **Mac:** `.dmg` — open it and drag Alter into Applications
- **Windows:** `.exe` installer

Video convert / spoof / subtitles need [ffmpeg](https://ffmpeg.org/download.html) on the machine (`brew install ffmpeg` or `winget install Gyan.FFmpeg`).

## Run from source

```bash
npm install
npm run tauri dev
```

```bash
npm run tauri build
```
